# 📌 Projet Frontend & Backend — Applications de Gestion
Ce projet regroupe deux applications développées en Frontend et Backend afin de mettre en pratique les opérations CRUD (Create, Read, Update, Delete) ainsi que la gestion et la manipulation de données.
---
# 🚀 Applications
## ✅ ToDoApp — Gestionnaire de tâches
Application permettant de gérer une liste de tâches à effectuer.
### Fonctionnalités
- ➕ Ajout de tâches
- 📋 Affichage des tâches
- ✏️ Modification des tâches
- ❌ Suppression des tâches
- ✔️ Validation des tâches
---
## 👤 ContactApp — Gestionnaire de contacts
Application de gestion de contacts réalisée sans backend.
### Fonctionnalités
- ➕ Ajout de contacts
- 📋 Affichage des contacts
- ✏️ Modification des contacts
- ❌ Suppression des contacts
- 🔎 Tri des contacts
- ✅ Vérification des informations
---
### Objectif
Mettre en pratique :
- la manipulation du DOM,
- le stockage local des données,
- la gestion dynamique des listes et formulaires.

# ▶️ Lancer le projet
## Démarrer le backend
Depuis le dossier `backend` :
```bash
node server.js
```
---
## Démarrer le frontend
Depuis la racine du projet :
```bash
npm run dev
```

# 📌 Projet Frontend & Backend — Applications de Gestion

Ce projet regroupe plusieurs applications développées en Frontend et Backend afin de mettre en pratique les opérations CRUD (Create, Read, Update, Delete), la gestion des utilisateurs, l’authentification et la manipulation de données.

---

# 🚀 Applications

## ✅ ToDoApp — Gestionnaire de tâches

Application permettant de gérer une liste de tâches à effectuer.

### Fonctionnalités

- ➕ Ajout de tâches
- 📋 Affichage des tâches
- ✏️ Modification des tâches
- ❌ Suppression des tâches
- ✔️ Validation des tâches

---

## 👤 ContactApp — Gestionnaire de contacts

Application de gestion de contacts réalisée avec backend.

### Fonctionnalités

- ➕ Ajout de contacts
- 📋 Affichage des contacts
- ✏️ Modification des contacts
- ❌ Suppression des contacts
- 🔎 Tri des contacts
- ✅ Vérification des informations

---

## 📰 React Articles App — Application de gestion d’articles

Application complète développée avec React.js et Node.js permettant à un utilisateur de s’inscrire, se connecter et gérer ses articles.

### Fonctionnalités

### 🔐 Authentification

- 📝 Inscription utilisateur
- 🔑 Connexion utilisateur
- 🔒 Authentification JWT
- 🚪 Déconnexion
- 🔐 Routes protégées

### 📰 Gestion des articles

- ➕ Création d’articles
- 📋 Liste publique des articles
- 👁️ Consultation du détail d’un article
- ✏️ Modification d’un article
- ❌ Suppression d’un article
- 👤 Affichage des articles de l’utilisateur connecté

### 🌐 Navigation

- 📌 Navbar dynamique
- 🚫 Page 404
- 🔄 Redirection automatique si non connecté

# ▶️ Lancer le projet

## 📦 Installer les dépendances Frontend

Depuis la racine du projet :

```bash
npm install
```

---

## 📦 Installer les dépendances Backend

Depuis le dossier backend :

```bash
npm install
```

---

## 🚀 Démarrer le backend

Depuis le dossier `backend` :

```bash
node server.js
```

Le backend démarre sur :

```bash
http://localhost:5000
```

---

## 🚀 Démarrer le frontend

Depuis la racine du projet :

```bash
npm run dev
```

Le frontend démarre sur :

```bash
http://localhost:5173
```
